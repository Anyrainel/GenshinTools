# Tailwind 4 shadcn refresh — 2026-10-12

Later on 2026-10-12, Card spacing was deliberately customized for existing
sectioned cards. See [local changes](../shadcn-customizations.md); Card is now
listed under `customizedComponents` rather than the stock hash checks below.

All 30 stock components in the prior audit were refreshed independently from
the live official `new-york-v4` Radix registry. The
[provenance manifest](shadcn-stock.json) records every source URL, upstream
content digest and installed digest. The [zero-context upgrade patch](shadcn-2026-10-12.patch)
records the exact previous-to-current differences without whitespace-only
context lines. Normalizations map registry imports to existing local owners,
normalize line endings and use one trailing newline. The repository already
excludes its UI directory from Biome formatting; stock formatting is retained.

The [previously approved fixes](shadcn-2026-10-11.md) remain above stock:

- Accordion focus padding remains in `FocusSafeAccordionContent`.
- Dialog overflow remains in `ScrollableDialogContent` and the custom
  `responsive-dialog` component.
- HoverCard content now portals in upstream itself. Both previous wrapper
  callers use stock `HoverCardContent`; the obsolete `PortalHoverCardContent`
  wrapper is removed instead of nesting portals or retaining a compatibility path.

Custom lightweight-select, lightweight-multiselect, weighted-select,
option-button, responsive-dialog and third-party tour remain custom. Their
Radix imports now resolve through `radix-ui`. No extra local base overrides are
preserved. Current stock Sonner expects complete CSS color values; the app's
Toaster call supplies `hsl(var(...))` values for the existing HSL theme tokens,
without modifying upstream Sonner.

The UI invariant guard verifies each stock file's SHA-256 after normalizing CRLF
to LF, rejects stock drift, and permits upstream styles only for those exact
files. Custom UI retains the existing invariant checks and debt limits.
