## Decisions

19 of 30 official components differed before upgrade. Nine differences were only missing upstream client directives; the remainder were local behavior, styles, or convenience APIs.

User-approved fixes moved above the stock base components: accordion focus padding to shared/FocusSafeAccordionContent, dialog overflow to shared/ScrollableDialogContent and the existing custom responsive-dialog, and hover-card portals to shared/PortalHoverCardContent.

Removed without preservation: reduced primary opacity, badge no-wrap default, soft/destructive-outline button variants, generic Select/Tabs APIs, onBooleanChange convenience API, altered unchecked switch color, textarea height/transition changes. Callers now use standard variants and native callback props. Custom UI components remain in place.
