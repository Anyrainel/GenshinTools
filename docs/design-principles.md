# Visual design principles

Robin Williams’s four principles from *The Non-Designer’s Design Book*.
Use them when reviewing a screen or changing how it looks.
`docs/frontend-design.md` still decides structure and reuse.

A character grid, icon row, or data table is one repeated group.
Count groups, not every icon inside a group.

## Proximity

Related items form one visual unit. Closeness is the clue to what belongs together.

- Put items that belong together close enough to read as one group.
- Leave a clearly larger gap between groups than inside a group. Equal spacing implies an equal relationship.
- Do not place unrelated items next to each other just because there is room.
- Squint and count every place the eye stops. More than three to five stops means some separate pieces should be pulled into one group. The exact count depends on the piece.
- The eye needs a definite start, a path, and a definite end. After the last item, there is an obvious next place to look.

## Alignment

Every element shares an edge with something else. Nothing sits in an arbitrary position.

- Each element lines up with at least one other element.
- Use only one text alignment on the page. Centered text and flush-left text on the same piece break the shared edge.
- Centered alignment is for a formal, sedate piece, and only when chosen on purpose. It is not the default.
- Once a strong flush edge exists, hook the other elements to that same edge.
- A gap that belongs to no group and lines up with nothing is trapped space. Remove it or give it to a group.

## Repetition

Repeat a visual element on purpose so the piece feels like one design.

- Repeat color, shape, texture, spacing, line thickness, font, size, or a graphic element across the whole piece.
- Make the repetition obvious enough that a heading, a card, or a control series is recognizable before the words are read.
- Keep a repeated treatment identical. A heading or button style that changes slightly from section to section reads as inconsistency.
- The same element should also tie separate pieces of one set together: pages in a section, or a dialog and the screen that opened it.
- Stop when the repeated element is so heavy or so frequent that it competes with the content. There is a fine line between a repetition that unifies and one that becomes annoying.

## Contrast

If two items are not the same, they must be very different. A slight difference looks like a mistake.

- Elements that are merely similar fail. Make them the same, or unmistakably different.
- Contrast is what makes someone look at the page. The strongest contrast is the focal point, not decoration on everything.
- Type has six levers: size, weight, structure (serif versus sans), form (caps, italic), direction, and color. A change has to be strong in that one lever.
- A small step is not contrast. Twelve-point next to fourteen-point, or black next to dark gray, still looks like the same thing.
- Do not be timid. Size, weight, color, or shape should jump.
