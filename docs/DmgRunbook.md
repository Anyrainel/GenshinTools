# Agent Audit Runbook

## 必备伤害公式
`formulaMap` 必须至少包括这个角色最核心的伤害来源，在不确定时也可以包括其他可能的伤害来源。下面的列表包括了必须涵盖的伤害公式，可以自行添加更多的伤害公式。【】中表示了显示该公式的条件，不满足时不要显示。另外公式的命名最好也加上命座和技能的前缀，如 “E ……”，“Q ……”，“2命E ……”，“6命普攻 ……”，可以灵活地微调公式名字使其更通顺。
