## roadmap
- 常驻：持续补充合理的伤害公式和自定义选项
- P0：更实用的强化、洗词条推荐
- P1：更好看的毕业特效
- P2：（远期）一键全角色配装推荐 + 导出 + 自动锁定 / 装备脚本

## 2025-03-31

### features
- 武器选择：新标签页，按排轴伤害排名所有兼容武器
- 圣遗物管理器：通过本地代理向游戏发送锁定/解锁和装备指令
- 精确副词条导入：Enka精确强化次数解码 + GOOD求解器还原
- 队伍配置页重构为伤害/冻结/补金三个标签页
- 冻结圣遗物：独立标签页，按队伍分区，支持独立冻结
- 补金分析：全页面视图，替代旧的分析对话框
- 评估页：支持按评级排序角色
- 改善空状态提示：为新用户显示预设引导说明

### fixes
- 修复了分拣页对受保护圣遗物发送锁定/解锁的问题
- 修复了多武器争夺同一部位时优化器的决胜逻辑

## 2025-03-29

### features
- 新增全技能等级模拟，不再强行使用10级/13级数据
- 按命座自动调整排轴：切换命座时排轴公式自动更新，显示各技能解锁的命座要求
- 所有公式现在在选择器中都会显示，并带有命座标签（如1命、2命），
- 补金分析排轴设置：可按命座自定义排轴组合和最低充能需求
- 丝柯克、公子被动自动激活：技能等级buff现在会正确地应用
- 部分GOOD导入：导入时仅覆盖文件中包含的数据类型，保留已有库存
- 更多角色公式：新增20+公式

### fixes
- 修复了图鉴中绫华和莫娜天赋表显示错误数值的问题（冲刺/大招参数错位）
- 修复了聚变反应、月感电、月结晶的伤害计算和显示
- 修复了不同属性的Buff被错误合并去重的问题

## 2025-03-26

### features
- 队伍配置页新增搜索、排序和筛选功能，方便管理大量队伍
- 新增复用模式：允许同角色复用，或强制同角色同套装复用已冻结圣遗物
- 面板重设计：战斗/非战斗属性视图，紧凑响应式布局
- 新增Buff逐条激活对话框：精细控制每段伤害的Buff生效状态和命中次数
- 自定义散件规则：用户自定义圣遗物散件搭配模式，支持添加/删除
- 支持冻结当前已穿着圣遗物
- 图片导出：主题化背景与自适应尺寸
- 多元素角色支持反应覆盖（恰斯卡、法尔伽）
- 页面切换加速：懒加载路由与预设缓存
- 首页素材转为WebP格式，加载体积减少75%

### fixes
- 修复了暴击模式未正确调整排轴总伤和单行伤害的问题
- 修复了圣遗物重复bug，重新设计饱和检测
- 修复了边际增益虚高问题，统一显示端和优化器的计算逻辑
- 修复了推荐页阈值筛选产生错误结果的问题

- 队伍详情页新增计算限制说明
- 更多角色和武器公式：丝柯克、香菱、白术、重云命6等

### fixes
- 修复了切换命座时Buff叠层分配未正确更新的问题
- 修复了生成圣遗物时未考虑Buff覆盖参数，导致生成结果不够优的问题
- 优化器和生成器现在使用编译公式计算排轴伤害，速度大幅提升
