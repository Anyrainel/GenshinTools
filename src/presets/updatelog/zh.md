## roadmap
- 常驻：持续补充合理的伤害公式和自定义选项
- P0：更实用的强化、洗词条推荐
- P1：更好看的毕业特效
- P2：（远期）一键全角色配装推荐 + 导出 + 自动锁定 / 装备脚本

## 2025-03-21

### features
- 公式现在支持脱手伤害计算，自动区分场上/脱手属性
- 新增补金分析：用图表展示补金顺序，可自定义补金起点、终点
- 新增Buff微调功能：可手动调整每段伤害的Buff生效状态、次数
- 自动调参批量模式：基于排轴数据一次性为多个角色调整词条权重
- 更多角色、武器、圣遗物公式与数据更新，支持更多选项
- 新公式编译器：大幅加快伤害计算速度

### fixes
- 修复了大量角色和武器增益的实现问题
- 改善了队伍配置页面在窄屏和中等宽度下的布局
- 修复了配装迁移问题，提升了数据存储稳定性

## 2025-03-16

### features
- 优化算法重做：更加优先最优结果，但耗时更长
- DPS角色配装支持自动调参：根据命座、精炼自动计算词条权重
- 圣遗物锁定、解锁推荐
- 更多角色公式

### fixes
- 修复了导入时其他元素的旅行者标记为未拥有的问题
- 修复了生成圣遗物时2+2套装时的错误
- 修复了无增益时优化圣遗物容易出0级的问题

## 2025-03-12

### features
- GOODScanner发布：全面的OCR扫描
- 推荐页重做：新UI，新算法，考虑暴击溢出问题（还会持续改进）
- 少于4人队伍优化支持
- 允许库存页删除已有物品

## 2025-03-11

### features
- 手动编辑账号数据
- 幽境危战原魔图鉴
- 允许手动调整优化后的圣遗物
- 暴击或充能需求较高时，可选择考虑纯散件配装
- 重做角色面板：显示各条件下的词条详情，以及公式所用各词条的最大值
- 新增敌方常驻元素选择，会调整可用公式与反应类Buff

### fixes
- 修复个别部位评分缺失的问题
- 修复部分角色与武器的实现问题
- 修复某些情况下优化会多次使用同一圣遗物的问题


## 2025-03-08

### features
- 直伤公式支持按队伍元素选择反应类型：蒸发、融化、原激化、蔓激化
- 多段伤害公式支持自定义各段是否触发反应
- 自由组合多角色、多公式，模拟排轴总伤
- 优化了自动配装算法，减少奇怪主属性和暴击溢出
- 可设定理想暴击值：牺牲期望伤害换取更高实际暴击伤害
- 新增西风武器最低暴击率约束
- 冻结已优化的圣遗物分配，冻结状态下须先解冻才能改配队
- 新增生成理想圣遗物功能，模拟极限伤害上限
- GOOD 格式导入时自动同步角色和武器的拥有状态
- 重做库存页面：显示已装备道具、更丰富的筛选功能

### fixes
- 评估页面现在正确显示圣遗物详情
- 提高了推荐页面的部分推荐阈值
- 修复了引导流程中页面卡住的问题
- 修复了部分角色的实现 bug
