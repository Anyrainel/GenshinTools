## roadmap
- 常驻：持续补充合理的伤害公式和自定义选项
- P0：更实用的强化、洗词条推荐
- P1：更好看的毕业特效
- P2：（远期）一键全角色配装推荐 + 导出 + 自动锁定 / 装备脚本

## 2025-03-12

### features
- GOODScanner发布：全面的OCR扫描
- 推荐页重做：新UI，新算法，考虑暴击溢出问题（还会持续改进）
- 少于4人队伍优化支持
- 允许库存页删除已有物品

## 2025-03-11

### features
- 手动编辑账号数据
- 幽境危战原魔图鉴
- 允许手动调整优化后的圣遗物
- 暴击或充能需求较高时，可选择考虑纯散件配装
- 重做角色面板：显示各条件下的词条详情，以及公式所用各词条的最大值
- 新增敌方常驻元素选择，会调整可用公式与反应类Buff

### fixes
- 修复个别部位评分缺失的问题
- 修复部分角色与武器的实现问题
- 修复某些情况下优化会多次使用同一圣遗物的问题


## 2025-03-08

### features
- 直伤公式支持按队伍元素选择反应类型：蒸发、融化、原激化、蔓激化
- 多段伤害公式支持自定义各段是否触发反应
- 自由组合多角色、多公式，模拟排轴总伤
- 优化了自动配装算法，减少奇怪主属性和暴击溢出
- 可设定理想暴击值：牺牲期望伤害换取更高实际暴击伤害
- 新增西风武器最低暴击率约束
- 冻结已优化的圣遗物分配，冻结状态下须先解冻才能改配队
- 新增生成理想圣遗物功能，模拟极限伤害上限
- GOOD 格式导入时自动同步角色和武器的拥有状态
- 重做库存页面：显示已装备道具、更丰富的筛选功能

### fixes
- 评估页面现在正确显示圣遗物详情
- 提高了推荐页面的部分推荐阈值
- 修复了引导流程中页面卡住的问题
- 修复了部分角色的实现 bug
