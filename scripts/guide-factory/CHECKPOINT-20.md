# Checkpoint 20: all-character guide-input coverage

This checkpoint inventories the current repository and captured source inputs
against an explicit character-by-constellation boundary. It is a descriptive
coverage baseline for later factory work, not a character guide or an
assessment of game quality.

## Durable result

The inventory covers all 125 guide-domain-eligible characters at C0 through C6,
producing 875 compact rows backed by 3,084 group-level observations. Each row
can be reconstructed from the observation ledger rather than treating compact
counts as independent authority.

Exactly five characters have no contributing guide input at any of the seven
boundaries:

- Aloy;
- Anemo Traveler;
- Electro Traveler;
- Geo Traveler;
- Hydro Traveler.

This means only that the current input repository has no contributing record.
It does not classify those characters as unsupported, unbuildable, or
unsuitable. In the other direction, evidence with unspecified constellation
applicability is not broadened into a universal C0-C6 claim.

The exact-team axis contains 888 member-investment observations. Of those, 887
leave constellation unspecified. The sole explicit member investment is C6
Diona. This exposes the current investment-specific evidence gap without
inventing C0 assumptions or propagating one team's scope to another.

## Evidence and policy linkage

All 57 upstream KQM manual records remain visibly unreviewed. The 56 non-energy
records contribute provenance or coverage without adding authority or promotion
eligibility; the energy-guidance record contributes no observation. The current
repository also contains zero repository-authored `damagePlans`, so the formula
axis does not manufacture plans from rotations, formula drafts, or calculator
defaults.

The report links 1,008 weapon and 1,068 artifact policy observations to the
exact classifications in the existing search-coverage reports. Linkage is not
a positive representability or compatibility result: 27 linked artifact
outcomes are explicitly not representable, and 12 linked weapon outcomes have
native type mismatches. Per-observation outcome payload hashes are
reconstructible only with those pinned upstream reports. None of this means
that a choice is suitable, executable, preferred, ranked, or complete.

Source grouping remains intact:

- raw stat weights are preserved as raw values and not converted to ordinal
  priority;
- page order and array order do not create recommendation rank;
- the one coupled multi-character artifact assignment remains one atomic plan
  rather than two independent choices;
- missing evidence remains distinct from negative or unsupported evidence;
- constellation-unspecified evidence remains distinct from universal evidence.

## Validation boundary

The durable validator rebuilds the coverage catalog, exact-byte-authenticated
source provenance, repository observations, roster-domain linkage, and fresh
weapon/artifact search-coverage reports from current inputs. Drift or a rebound
but incomplete dependent report cannot be hidden by a structurally valid saved
report.

This checkpoint emits no character guide, recommendation, ranking, winner,
formula plan, damage result, or gameplay claim. It does not infer that a missing
input is bad, or that a present input is correct.
