# Checkpoint 55: Noelle Hexerei equipment response surface

This checkpoint composes the authenticated Noelle team, equipment, investment,
and exact Normal-prefix representation into a 48-cell offline technical response
surface. It deliberately stops before substat marginal work: a live threshold
probe showed that one witness per source branch would hide interaction changes.

It is not a working guide factory, build score, optimizer result, or player-facing
recommendation.

## Why the initial two-witness design was rejected

The first planned grid used one C0/Q9 witness for the lower source branch and one
C6/Q10 witness for the high branch. Before committing that design, a bounded
prototype evaluated another satisfying lower-branch point. Under the same static
fixture, C0/Q9 favored the source-listed ATK% Sands, while C5/Q9 slightly favored
the DEF% counterfactual.

That is enough to reject a branch-level conclusion from one witness. The durable
surface therefore uses six threshold-relevant request points and retains their
individual signed responses. It computes no branch average.

## Runtime buff trace

An empty computed formula-override map is not treated as an empty buff state.
Each cell records:

- the complete registered buff-ledger hash;
- the applicable on-field-Noelle buff count and trace hash;
- static entries, dynamic phase, and resolved dynamic entries for every
  applicable buff;
- exact refinement-scaled Gest DMG/CRIT DMG and fixed Attack Speed entries;
- exact four-stack Husk DEF/Geo entries;
- both exact Geo resonance DMG/RES entries; and
- the verified absence of implemented buffs on the three teammate weapons.

The resolved objective stat snapshot reads the calculator's normalized tagged
`dmg%` bucket for a Geo Normal hit. It therefore records 1.156 at R1 in the
first cell rather than incorrectly querying the now-normalized `geo%` alias.
Artifact-sheet hashes preserve each normalized entry's filter key, so a Geo
Goblet cannot hash identically to a different elemental Goblet.

The 48 cells contain 24 unique applicable-buff traces because Circlet changes do
not change the resolved dynamic buff ledger while investment, Sands, and
refinement can. Applicable counts are 13, 14, or 15 depending on constellation.

These traces describe current static calculator state. They do not establish
source action timing or buff duration coverage.

## Single-axis comparisons and observed response

The report constructs 72 comparisons: 24 Sands pairs, 24 Circlet pairs, and 24
refinement pairs. Every pair is checked to differ in exactly one declared axis.
It retains signed left-minus-right deltas and no winner, rank, selection, or
source-expected ordering.

For the source-listed Sands versus the branch-local counterfactual, all four
Circlet/refinement cells at each witness had the same sign:

- C0/Q9: source-listed ATK% positive in 4/4;
- C5/Q9: source-listed ATK% negative in 4/4;
- C0/Q10: source-listed DEF% negative in 4/4;
- C5/Q10: source-listed DEF% positive in 4/4;
- C6/Q9: source-listed DEF% positive in 4/4; and
- C6/Q10: source-listed DEF% positive in 4/4.

Both source branches therefore show cross-witness sign variation under this one
technical fixture. The report explicitly computes no branch average and supports
no branch-wide Sands claim. This is a useful validation target: a future guide
factory that emits one unconditional branch result would need a stronger policy
or more context.
