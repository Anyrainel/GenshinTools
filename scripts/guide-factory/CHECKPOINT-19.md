# Checkpoint 19: authenticated source-conditioned technical matrix

This checkpoint runs the first bounded generator matrix whose Keqing target is
composed from authenticated source claims. It remains a structural experiment,
not a guide or comparison.

## Durable result

The wrapper freshly rebuilds and authenticates the checkpoint-18 contract, then
derives exactly two full-payload Keqing targets for the published
Keqing/Ineffa/Furina/Xilonen team:

- Mistsplitter Reforged plus 4pc Marechaussee Hunter;
- Mistsplitter Reforged plus the exactly-one-Nod-Krai branch of 4pc Night of
  the Sky's Unveiling.

Both retain ATK% Sands, Electro DMG or ATK% Goblet, CRIT DMG Circlet, and the
three source substat groups as validation observations. The unresolved CRIT
Rate Circlet and two-Nod-Krai artifact branch remain withheld. Ineffa, Furina,
and Xilonen use exact repository build targets from the validated fixture.

The two artifact nodes run once under Keqing, Ineffa, Furina, and Xilonen carry
seeds. The current report therefore contains eight structurally completed
cells from eight fresh sequential `TeamBuild` instances, with maximum
concurrency one.

## Authentication and failure boundary

Both candidates, all four validation targets per candidate, temporary runtime
teams, and formula shapes are checked before call one. Composed targets are
default-deny and accepted only by a frozen capability backed by private
process-local full-payload hashes. The complete prepared plan is cloned before
the first asynchronous step, so mutation of the caller's repository, formula,
targets, nodes, or capability cannot alter later cells.

Execution stops at the first failure. A report is comparable only after all
eight calls, eight distinct team identities, eight runtime source validations,
and eight structural observations complete. Partial node payloads and the
origin ledger are removed on failure.

The declared `generatedFrom` list binds direct evidence, wrapper, and runtime
paths; it is not presented as a transitive module closure. The durable
validator re-executes the current runtime and compares the complete report, so
effective output drift cannot pass merely because a transitive file was absent
from that direct list.

## Provenance distinctions

The formula fixture's selected artifacts are retained only as seed provenance.
Every runtime artifact assignment comes from the matrix node; the three
teammate assignments happen to match their fixture seeds, while Keqing's
Thundering Fury seed is replaced by the node's Marechaussee or Night target.

Source and repository stat arrays are post-generation observations. They are
not passed as generator constraints or scoring weights. The eleven unreviewed
formula lines and their hit counts remain serialized as the generator's
internal technical objective specification, but no evaluated objective value
or damage value is retained.

## What this does not establish

The matrix performs no cross-node objective comparison and no artifact-set
comparison. It creates no source-authored build, recommendation, stat priority,
ideal-roll allocation, score, rank, winner, damage claim, or ER requirement.
Record-local `default` and `alternative` labels remain unrelated across their
separate source records. ER work remains deferred.
