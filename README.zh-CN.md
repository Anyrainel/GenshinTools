## 🛠️ 包含工具

### 圣遗物过滤助手

**定制你自己的圣遗物过滤器！**

每个人玩原神的方式都不一样。这个工具可以让你：

- **分角色配装**：根据你的具体需求为每个角色设定配装方案（套装 + 词条）。
- **预设订阅**：订阅社区精选预设，然后在其基础上自定义。支持单独还原配装或整体恢复角色到预设默认值。
- **智能合并**：两种合并算法（贪心算法求快速、智能算法求最优）将配装需求合并成紧凑的过滤器配置。
- **分享与导入**：轻松分享你的配置或导入社区的方案。

### 账号数据分析 (Account Analytics)

**可视化你的账号进度。**

- **数据导入**：通过 **GOOD** 文件（来自扫描器）或 **Enka.Network**（UID）导入数据。
- **圣遗物评分**：基于自定义词条权重自动为你的角色圣遗物评分。
- **个性化推荐**：获取可执行的建议，了解哪些角色和圣遗物值得投资。
- **库存概览**：查看账号内圣遗物和武器的分布情况。

### 强度榜制作器

**创建和管理角色及武器强度榜。**

一个现代化的交互式强度榜制作工具：

- **按元素分类**：在每一层级内，角色按元素自动排序，更加清晰。
- **角色 & 武器标签**：在统一视图中切换角色和武器强度榜。
- **保存/加载**：将你的强度榜保存为 JSON 文件，随时加载修改，也可以订阅社区预设。
- **拖拽操作**：简单易用的界面。
- **图片导出**：一键生成高清图片分享你的榜单。

### 图鉴 (Archive)

**浏览完整的角色和武器百科全书。**

- **角色详情**：查看多个突破等级的基础属性、完整技能/天赋、固有天赋、命座和词典。
- **武器详情**：按类型、副词条和稀有度对比武器。

### 队伍构建器

**可视化构筑你的理想队伍。**

- **直观规划**：在卡片式布局中选择角色、武器和圣遗物。
- **智能交互**：带有筛选功能的智能选择器（例如仅显示角色可用的武器）。
- **管理功能**：创建、复制并管理多个队伍配置。

## 🖥️ 桌面版应用

**原生性能与离线支持。**

本应用使用 **Tauri** 构建，支持作为 Windows 桌面应用运行，无需浏览器即可使用，且性能更加出色。

## 💻 技术栈

- **框架**: React, TypeScript, Vite
- **UI**: Tailwind CSS, shadcn/ui
- **状态管理**: Zustand
- **桌面端**: Tauri
