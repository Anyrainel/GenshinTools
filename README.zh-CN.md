## 它能做什么

- **管理圣遗物**：根据仓库和配装目标生成自动锁定、解锁、保留、强化和合成候选。
- **优化队伍伤害**：给定队伍和完整仓库，找出更适合该队伍伤害目标的圣遗物分配。
- **评估角色练度**：给当前配装评分，查看配装缺口，并判断哪些角色还需要更好的部件。
- **计算游戏内过滤器**：把角色配装目标转化为圣遗物套装和部位过滤规则。
- **推演配装选择**：在明确假设下比较武器、圣遗物分配、命座和精炼变化。
- **制作可分享榜单**：维护角色、武器和圣遗物榜单，并导出图片或 JSON。
- **快速查资料**：在应用内浏览内置角色、武器、圣遗物套装和地脉首领资料。

## 从这里开始

- **导入账号数据**：支持 GOOD JSON、GOODScanner / GOODCapture、Enka UID，或 HoYoLAB / 米游社。
- **设置角色优先级**：在榜单里排好角色优先级，让账号推荐知道哪些配装更重要。
- **查看角色配装**：在账号数据里查看评分、配装缺口和提分建议。
- **优化一个队伍**：在队伍伤害里从你的仓库中寻找更高伤害的圣遗物分配。

## 工具

### 账号数据

用导入的账号数据管理圣遗物，并判断哪些角色配装值得优先提升。

- 导入 GOOD JSON、Enka UID 数据，或 HoYoLAB / 米游社角色数据。
- 查看已拥有角色、已装备圣遗物、武器、仓库记录和圣遗物评分。
- 当来源数据需要修正时，手动编辑角色、武器和圣遗物记录。
- 按角色优先级分配圣遗物，并估算提分、强化或合成价值。
- 用当前账号数据评估已配置的圣遗物配装。
- 规划祝圣精华、祝圣之霜和启圣之尘的使用方向。
- 生成圣遗物锁定、解锁和保留建议，用于整理仓库。

### 配装

定义圣遗物配装目标，并转化为实际刷本或筛选规则。

- 配置圣遗物套装、主词条、副词条权重、武器假设和配装可见性。
- 导入内置配装预设，或将自己的配装配置导出为 JSON。
- 根据已配置配装计算圣遗物套装和部位过滤器。
- 使用 AutoTune 从队伍伤害场景推导初始权重。

### 队伍伤害

建模队伍，并用你的仓库优化队伍伤害。

- 导入队伍预设，或维护自己的队伍列表。
- 在增益、反应、元素共鸣、敌人假设和公式细节下计算队伍伤害。
- 从账号仓库里搜索更强的圣遗物分配。
- 保存并查看冻结的优化结果。
- 比较命座、精炼等投入变化。
- 为指定队伍比较武器和圣遗物重分配方案。

### 榜单

维护用于规划和分享的个人排名表。

- 制作角色、武器和圣遗物榜单。
- 导入预设、编辑条目、筛选榜单，并导出 JSON。
- 导出榜单图片，便于分享。
- 将角色优先级作为账号提分推荐的输入之一。

### 图鉴

不用切到其他资料站，也能浏览内置游戏资料。

- 角色技能组、属性、固有天赋、命座和词条说明。
- 武器属性、特效、稀有度和类型筛选。
- 圣遗物套装效果和半套过滤。
- 地脉首领资料，并支持按开放日程默认选择。

## 导入与数据说明

- 完整仓库流程依赖 GOOD 格式导出，或 GOODScanner / GOODCapture 等配套工具。
- Enka UID 导入只包含公开展柜角色及其装备。
- HoYoLAB / 米游社导入需要用户自行提供 Cookie。
- 应用数据主要保存在浏览器本地；可选账号登录会为受支持的应用数据启用云端备份。

## 本地开发

```bash
npm install
npm run dev
npm run type-check
npm run lint
npm run test
npm run build
```

常用变体：

- `npm run dev:worker` 启动本地 Worker 开发服务器。
- `npm run depcheck` 检查依赖边界。
- `npm run regtest` 运行圣遗物生成器回归测试。
- `npm run check:worker` 运行 Worker 配置、构建、测试和 dry-run 检查。

## 技术栈

- React 19、TypeScript、Vite 7
- Tailwind CSS、shadcn/ui、Radix primitives、Vaul、Lucide icons
- Zustand、Immer、persist middleware
- Cloudflare Workers
