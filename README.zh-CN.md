## 它能做什么

Genshin Tools 用来把账号数据、配装目标和队伍方案转化成具体决策：练谁、锁什么、升什么、换什么，以及不同优化方案会怎样影响队伍表现。

## 工具

### 账号数据

导入账号数据，并在整个应用中复用。

- **角色**：查看已拥有角色、已装备圣遗物、圣遗物评分，并编辑账号记录。
- **仓库**：查看武器、圣遗物和角色；从游戏同步；查看账号数据最近更新时间。
- **提分推荐**：按角色优先级寻找圣遗物替换与强化建议，并将可执行方案发送到 Artifact Manager 流程。
- **圣遗物评估**：用当前圣遗物评估已配置配装，按套装与角色查看完成度。
- **资源投入规划**：规划祝圣精华、祝圣之霜、启圣之尘的使用方向。
- **锁定助手**：判断圣遗物应锁定、解锁或保持保护状态，并生成可应用到游戏的锁定指令。

支持 GOOD JSON、Enka UID 和 HoYoLAB 导入。

### 圣遗物过滤

配置角色配装目标，并生成过滤结果。

- **配置配装**：定义每个角色的圣遗物套装、词条权重、武器假设和配装可见性。
- **计算过滤器**：将已配置配装合并成用于刷本和筛选的套装/部位过滤结果。
- **AutoTune**：从队伍伤害场景推导配装权重，适合作为进阶起点。

### 队伍配装

构建、比较和优化队伍。

- **伤害**：计算队伍伤害，涵盖增益、反应、元素共鸣、敌人假设和透明的公式细节。
- **冻结方案**：查看冻结的圣遗物/队伍结果，并导出批量装备指令。
- **投入对比**：比较指定队伍的命座、精炼等投入变化。
- **武器选择**：为指定队伍比较武器方案与圣遗物重分配方案。

### 榜单

创建和分享个人排名表。

- **角色**：维护角色优先级，并作为账号提分推荐的输入。
- **武器**：制作武器榜单，便于记录或分享。
- **圣遗物**：按分类制作圣遗物套装榜单。
- **导出**：支持保存/读取 JSON，并导出高清图片。

### 图鉴

在应用内查询内置游戏资料。

- **角色**：技能组、属性、固有天赋、命座、词典，以及嵌入式配装/账号上下文。
- **武器**：武器属性、特效、稀有度、类型和持有状态。
- **圣遗物**：套装效果、半套过滤和套装详情。
- **Boss**：地脉首领资料，支持按开放日程默认选择与详情查看。

## 本地开发

```bash
npm install
npm run dev
npm run type-check
npm run lint
npm run test
npm run build
```

常用变体：

- `npm run dev:wrangler` 在 Wrangler Pages dev 代理后启动 Vite。
- `npm run depcheck` 检查依赖边界。
- `npm run regtest` 运行圣遗物生成器回归测试。

## 技术栈

- React 19、TypeScript、Vite 7
- Tailwind CSS、shadcn/ui、Radix primitives、Vaul、Lucide icons
- Zustand、Immer、persist middleware
- Cloudflare Pages/Workers
